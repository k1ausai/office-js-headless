# Security Policy

## Supported Versions

Pre-1.0: only the latest published version on npm is supported.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities. Instead, use GitHub's private
reporting:

https://github.com/k1ausai/office-js-headless/security/advisories/new

Include steps to reproduce, affected version, and impact if known. We'll acknowledge within a few
business days.
